# Catálogo de Rituais

O arquivo `data.js` agora inclui **~55 rituais** com campos:

- Nome, Elemento, Círculo
- Execução, Alcance, Área, Alvo, Duração
- Efeito, Resistência
- Dados / Dados Discente / Dados Verdadeiro

Na aba **Rituais** use a busca e os filtros de elemento/círculo.

Botões:
- **Adicionar** — coloca o ritual na ficha
- **Ver** — abre o modal pré-preenchido

Resumos públicos — consulte o livro oficial para regras completas.
