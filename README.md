# Escandinavo Fichas — Ordem Paranormal RPG

Sistema funcional de criação e personalização de fichas.

## Novidades
- **Catálogo de Rituais com busca** (nome, elemento, círculo)
- Modal Novo Ritual (campos C.R.I.S.)
- Modal Novo Ataque
- Inventário estilo C.R.I.S.
- Auto-save localStorage

## Uso
Abra `index.html` no navegador.
